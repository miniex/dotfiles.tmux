# Contributing

Thanks for the interest.

This is a personal dotfiles repo, tuned for one setup and kept in step with [dotfiles.kitty](https://github.com/miniex/dotfiles.kitty), [dotfiles.nvim](https://github.com/miniex/dotfiles.nvim) and [fish-theme-damin](https://github.com/miniex/fish-theme-damin), so outside contributions are not accepted. Pull requests get closed politely, and so do issues that aren't bug reports for the published behavior.

Two things are welcome:

- **Fork it.** It's MIT licensed, so take what's useful and change whatever you like.
- **Open an issue** if something is plainly broken: `install.sh` crashes, `bin/theme.sh` or `bin/update.sh` errors out, the gradient script fails, a documented keybinding does nothing. Include your OS, `tmux -V`, and the exact command or steps.

New themes, new OS profiles and feature requests belong in your fork. I won't merge them here.

Thanks again for understanding.

Han Damin
